# v1.0.0 — analysis code for the CD207+ Langerhans/DC re-analysis in psoriasis

Release date: 2026-11-15

Code accompanying the manuscript:

> **Reduced CD207+ Langerhans-cell transcriptomic signature in lesional psoriasis:
> a transparency-focused two-group single-cell re-analysis with replication across
> three independent bulk cohorts** — Huiyu Zhang, Dongmei Shi

## What this release contains

| Path | Contents |
|---|---|
| `R/` | 25 analysis and figure-rendering scripts: identifier harmonisation, cell-level QC and doublet removal, Harmony integration, lineage annotation, myeloid/DC subclustering, donor-level pseudobulk proportions, the pre-specified one-sided Jonckheere–Terpstra permutation test with Benjamini–Hochberg correction, two-group pseudobulk differential expression, GO/Hallmark enrichment, GSVA, label transfer, three independent bulk validations, structural-zero correction, composition controls and empirical null, maturation axis, transcription-factor activity, and the figure scripts for Figures 1–4 and Supplementary Figures S1–S6 |
| `py/` | GEO feasibility pilot, mapping-free marker counting, DOI verification, and the Markdown-to-Word converter used for the submission files |
| `config/` | `00_paths.R` (relative paths only), frozen `01_params.R`, additive `02_s8_params.R` |
| `scripts/00_fetch_data.sh` | downloads GSE173706, GSE162183, GSE13355, GSE14905 and GSE30999, verifies SHA-256 checksums, builds the directory layout the scripts expect |
| `logs/ANALYSIS_SUMMARY.md` | stage order, the five frozen decision gates, and every correction recorded after the freeze |
| `README.md`, `ENVIRONMENT.md`, `CITATION.cff`, `.zenodo.json`, `LICENSE` | documentation, environment snapshot, citation metadata, MIT licence |

## What this release does NOT contain

- **No data.** All five series are public and must be downloaded from GEO; they are not redistributed here.
- **No intermediate objects and no derived result tables.** Those are shipped in the article's supplementary archive and are regenerated by running the scripts.
- **No manuscript files.** The Word submission files and their sources live outside this repository.

## Reproducing

```bash
bash scripts/00_fetch_data.sh     # about 2 GB; verifies SHA-256
Rscript R/01_id_map.R             # then follow the stage order in logs/ANALYSIS_SUMMARY.md
```

Every R script sources `config/00_paths.R` first and must be run from the repository
root. Single seed for the whole project: `20261112`. Scripts are ASCII-only.

## Scope and known limits

This is a secondary analysis of public cohorts. The label-transfer AUC is **internal**
cross-validation, not external validation; the 3-versus-3 direct marker counts are
descriptive; GSVA at 3 versus 11 pseudo-samples is uninformative rather than negative;
the ordered three-state trend is specification-dependent; and the S8–S16 layer is
post hoc and does not enter any pre-specified gate. All of these limits are stated in
the manuscript and are not softened in the code.
